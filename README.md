Gerador de Landing Pages utilizando Inteligência Artificial (API Groq/Llama) para criação rápida de estruturas em HTML e CSS

# ⚡ DevClub — Gerador de Sites com IA

Este é um projeto de um **Gerador de Landing Pages com Inteligência Artificial**. Com ele, você pode descrever o seu negócio (ex: uma cafeteria, uma agência, um mercado) e a IA gera automaticamente o código HTML e CSS de uma página profissional para você.

## 🚀 Como funciona

O projeto utiliza a API da **Groq** para processar o seu prompt e gerar, em segundos, uma estrutura visualmente impressionante, utilizando boas práticas de CSS moderno, tipografia forte e layouts responsivos.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilização com foco em design moderno (Flexbox, gradientes, animações).
- **JavaScript (ES6+)**: Lógica de conexão com a API e manipulação do DOM.
- **API da Groq**: Processamento inteligente via modelo `llama-3.3-70b-versatile`.

## ⚙️ Configuração do Ambiente

Este projeto está configurado para rodar no VS Code com a porta **5501**.

1. Clone este repositório.
2. Certifique-se de ter a extensão **Live Server** instalada no seu VS Code.
3. Abra o arquivo `index.html`.
4. Clique em "Go Live" (ou use a porta 5501).

## ⚠️ Nota Importante

Para que o gerador funcione, você precisa inserir a sua própria `apiKey` da Groq no arquivo `scripts.js` na variável `apiKey`. 

*Nota: Nunca suba sua chave de API para repositórios públicos no GitHub!*
